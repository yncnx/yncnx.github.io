Twikoo简介

  Twikoo是一个简洁、安全、免费的静态网站评论系统。有部署有数种方式，其他部署方式要么收费，要么需要服务器，本次选择Vercel 部署，请选择适合自己的部署平台。Twikoo 支持匿名评论、邮件提醒、垃圾评论过滤等功能，非常适合部署在各类静态博客上。

一.Twikoo评论系统配置

  Twikoo 的后端数据存储使用 MongoDB，通过 Vercel 部署云函数来提供 API 服务，实现完全免费的评论后端方案。

1.配置MongoDB

  首先需要申请 MongoDB Atlas 免费数据库账号，创建集群并获取数据库连接字符串，后续 Vercel 部署时需要用到该连接字符串作为环境变量。

  1. 申请 MongoDB 账号。
  2. 创建免费 MongoDB 数据库，区域推荐选择 AWS / N. Virginia (us-east-1)。
  3. 创建数据库用户和数据库密码。
  4. 设置允许所有 IP 地址的连接。
  5. Clusters 页面点击 CONNECT - Drivers，记录数据库连接字符串,将连接字符串中的 <password> 修改为数据库密码。

2.配置 Vercel

  MongoDB 配置完成后，接下来通过 Vercel 一键部署 Twikoo 云函数，并将数据库连接字符串配置为环境变量。

  1. 申请 Vercel 账号。
  2. 点击Vercel按钮将 Twikoo 一键部署到 Vercel。
  3. 进入 Settings - Environment Variables，添加环境变量Key： MONGODB_URI，Value值为第 1.5 步的数据库连接字符串。
  4. 进入 Deployments , 点击头像后面三个点（更多） , 然后点击Redeploy , 最后点击下面的Redeploy。
  5. 进入 Overview，点击 Domains 下方的链接，如果环境配置正确，可以看到 “Twikoo 云函数运行正常” 的提示。
