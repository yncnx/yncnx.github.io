简介

  Welcome to Hexo! This is your very first post. Check documentation for more info. If you get any problems when using Hexo, you can find the answer in troubleshooting or you can ask me on GitHub.

  Hexo 是一个快速、简洁且高效的博客框架，基于 Node.js 运行，使用 Markdown 解析文章，通过主题生成静态网页文件。它拥有丰富的插件生态与主题资源，适合搭建个人技术博客与知识库。

Quick Start

  More info: Writing

Run server

  More info: Server

Generate static files

  More info: Generating

Deploy to remote sites

  More info: Deployment

常用指令说明

  以上四条命令是 Hexo 日常使用的核心指令：hexo new 创建新文章，hexo server 启动本地预览，hexo generate 生成静态文件到 public 目录，hexo deploy 将静态文件部署到远程仓库或服务器。更多高级用法请参阅 Hexo 官方文档。

安装与环境要求

  使用 Hexo 前需要先安装 Node.js 和 Git。Node.js 提供运行环境，Git 用于版本管理与部署。安装完成后通过 npm install -g hexo-cli 全局安装 Hexo 命令行工具，即可在任意目录使用 hexo 命令初始化博客项目。

文章编写

  Hexo 文章使用 Markdown 语法编写，文件存放在 source/_posts 目录下。每篇文章顶部使用 YAML front-matter 定义标题、日期、标签、分类等元信息。通过主题模板渲染，Markdown 内容会被转换为美观的 HTML 页面，支持代码高亮、数学公式、目录导航等功能。

  编写文章时，可以使用 hexo new "文章标题" 命令快速创建，Hexo 会在 _posts 目录下生成对应的 Markdown 文件。文章正文支持标准 Markdown 语法，包括标题、列表、引用、链接、图片等元素。对于技术博客，代码块语法高亮是常用功能，使用三个反引号加语言名称即可实现。

主题与配置

  Hexo 的外观由主题决定，主题文件存放在 themes 目录下。切换主题只需修改站点配置文件 _config.yml 中的 theme 字段。每个主题通常有自己的配置文件，用于控制导航栏、侧边栏、评论系统、社交链接等界面元素的显示与样式。

  站点配置文件 _config.yml 位于博客根目录，用于设置站点标题、描述、作者、语言、时区、URL 等全局信息。部署配置也在此文件中设置，指定部署目标和仓库地址。合理配置站点与主题两个配置文件，可以打造出个性化且功能完善的博客站点。

部署与发布

  Hexo 支持多种部署方式，包括 Git、GitHub Pages、Netlify、Vercel 等。最常见的是通过 hexo deploy 命令将生成的静态文件推送到远程仓库。也可以结合 GitHub Actions 实现自动化部署，每次推送源码后自动构建并发布，省去本地编译的繁琐步骤。

  部署前需要确保 hexo generate 已成功生成静态文件。生成的文件默认存放在 public 目录下，包含 HTML、CSS、JavaScript 及其他静态资源。部署过程中这些文件会被上传到目标服务器或仓库，用户访问博客域名时即可看到最新内容。
